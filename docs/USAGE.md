\# 📖 Usage Guide – Maureonix v5.0.0



This guide covers day‑to‑day use of the Maureonix bot. Whether you're an end user in a group or the bot owner, you'll learn how to execute commands, interpret responses, and get the most out of Maureonix.



---



\## 🚦 Getting Started



\### Prefix



All commands start with a \*\*prefix\*\*. The default prefixes are:

. ! #





\*\*Example:\*\* `.menu` or `!ping`



> ⚠️ Some groups may have custom prefixes. Ask the group admin if the default doesn't work.



\### First Command: `.menu`



Type `.menu` to see the \*\*interactive carousel menu\*\*. Swipe left/right to explore categories: Bot, Group, AI, Download, Games, etc.



If the carousel fails, a fallback image or text menu is sent.

\## 💬 Basic Interaction



\### Check if Bot is Online



.ping

\*\*Response:\*\* `🏓 Pong! Response: 120 ms`



\### View Bot Information



.info

\*\*Response:\*\* Bot name, owner, version, uptime, number of users/groups.



\### Contact Owner

.owner

\*\*Response:\*\* A contact card with the owner's WhatsApp number.

\## ❓ Frequently Asked Questions



\### Q: The bot doesn't respond to commands.

\*\*A:\*\* Check the prefix (usually `.`). Ensure the bot is online (`.ping`). If in a group, ensure the bot isn't muted (`.unmute` – owner only).



\### Q: I got "You have reached your daily limit."

\*\*A:\*\* Free users have a limited number of commands per day. Upgrade to premium or wait until reset (midnight).



\### Q: Download from YouTube fails.

\*\*A:\*\* Ensure `yt-dlp` is installed and up‑to‑date. The bot will show a specific error message.



\### Q: AI commands return errors.

\*\*A:\*\* Check that the API keys (`geminiApiKey`, `groqApiKey`) are valid and have not exceeded rate limits.



\### Q: How do I pair my own number (JadiBot)?

\*\*A:\*\* Use `.pair <your number>`, then `.startjadibot` after linking your device in WhatsApp settings.
